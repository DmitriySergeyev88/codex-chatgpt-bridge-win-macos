# ChatGPT App Setup / 在 ChatGPT 里创建 App

How to connect ChatGPT to your local bridge: developer mode, app URL, OAuth authorization, and
the read-only smoke test.

## English

The ChatGPT UI changes between versions, but the configuration fields below stay the same.

### Before you start

Finish the local setup first — this page only covers the ChatGPT side:

1. The skill is installed and low-level `Doctor` passes. See [README.md](README.md#quick-start).
2. A controller profile is saved with the exact project root you intend to expose.
3. The bridge is running via controller `On`, and you have the `mcpUrl` it printed.

If you do not have the `mcpUrl` handy, read it back without restarting anything:

```powershell
$skill = "$env:USERPROFILE\.codex\skills\codex-chatgpt-bridge"
powershell -ExecutionPolicy Bypass -File "$skill\scripts\bridge_controller.ps1" -Action Status
```

Prefer a stable Worker or proxy URL over a raw Quick Tunnel URL. A Quick Tunnel URL rotates on
restart, so an app saved against it will need editing later — see
[Reboot Without Relinking](README.md#reboot-without-relinking).

### 1. Enable Developer mode

In ChatGPT:

```text
Settings → Apps → Advanced settings
```

Turn on Developer mode.

### 2. Create the app

```text
Settings → Apps → Manage → Create app
```

Fill in:

```text
Name: Codex ChatGPT Bridge
URL:  your mcpUrl, e.g. https://your-stable-domain.example.com/mcp
Auth: OAuth
```

The URL must end in `/mcp`. For a quick test you can paste the Quick Tunnel `mcpUrl` the script
printed, but expect to edit it after the next restart.

### 3. Authorize

ChatGPT opens an authorization page that asks for the **Owner password**. That value is the
`ownerToken` generated by the bridge as 32 random bytes, stored locally at:

```text
%USERPROFILE%\.devspace\auth.json
```

Read it from that file and type it into the browser form yourself.

- Confirm the exposed project root is correct and narrow **before** approving.
- Never paste the Owner password, `ownerToken`, OAuth secrets, cookies, or API keys into a chat
  message, an issue, or a screenshot.
- The `/authorize` form has no rate limit or lockout. It is safe only because the token is
  high-entropy, so never replace it with something memorable.

Ran `Rotate`? All previous authorizations are revoked and a new Owner password is written to the
same file. Re-authorize with the new value.

### 4. Read-only smoke test

Before giving ChatGPT any real task, confirm it sees the workspace you expect:

```text
Open the current workspace through Codex ChatGPT Bridge and list only the top-level files.
Do not write any files and do not run any mutating commands.
```

Check that the listed files match the project root you configured. If they do not, stop and run
controller `Off`, then fix the profile before continuing.

### Troubleshooting

| Symptom | Cause and fix |
|---|---|
| ChatGPT reports the app is unreachable | The bridge is off or the tunnel moved. Run controller `Status`, then `On` if it is stopped. |
| It was working, now it 404s or times out | The Quick Tunnel URL rotated. Put a stable Worker or proxy in front, or update the app URL. |
| The authorization form rejects the password | You are reading a stale `auth.json`. `Rotate` replaces the value; re-read the file. |
| Authorized, but ChatGPT sees the wrong files | `ProjectRoot` / `AllowedRoots` point somewhere else. Run controller `Doctor` and check the reported roots and `securityWarnings`. |
| ChatGPT still lists the app after `Off` | Expected. `Off` closes reachability but keeps the app record so the next `On` needs no setup. Use `Rotate` to actually revoke tokens. |

### Security reminder

Once authorized, the bridge grants file read/write and shell execution as your Windows user, and
`run_shell` is not confined to the root. Keep the root narrow, use controller `Off` when idle,
and read the Security Model section in [README.md](README.md#security-model) before exposing
anything you care about.

## 简体中文

ChatGPT 的界面会随版本变化，但下面这些配置项基本不变。

### 开始之前

先完成本地部分，这份文档只讲 ChatGPT 那一侧：

1. skill 已安装且底层 `Doctor` 通过，见 [README_zh.md](README_zh.md#安装)。
2. 已用准确的项目目录保存 controller profile。
3. 已通过 controller `On` 启动桥，并拿到它输出的 `mcpUrl`。

如果手头没有 `mcpUrl`，不用重启，直接读回来：

```powershell
$skill = "$env:USERPROFILE\.codex\skills\codex-chatgpt-bridge"
powershell -ExecutionPolicy Bypass -File "$skill\scripts\bridge_controller.ps1" -Action Status
```

优先用稳定 Worker 或代理 URL，不要直接用 Quick Tunnel URL —— 后者重启就变，存进 app 之后早晚要改，
详见[让 ChatGPT 不用每次重新设置](README_zh.md#让-chatgpt-不用每次重新设置)。

### 1. 打开开发者模式

在 ChatGPT 中进入：

```text
Settings → Apps → Advanced settings
```

打开 Developer mode。

### 2. 创建 App

```text
Settings → Apps → Manage → Create app
```

填写：

```text
Name: Codex ChatGPT Bridge
URL:  你的 mcpUrl，例如 https://your-stable-domain.example.com/mcp
Auth: OAuth
```

URL 必须以 `/mcp` 结尾。临时测试可以先填脚本输出的 Quick Tunnel `mcpUrl`，但下次重启后大概率要改。

### 3. 授权连接

ChatGPT 会打开授权页面，要求填 **Owner password**。这个值就是桥生成的 `ownerToken`（32 字节随机数），
保存在本机：

```text
%USERPROFILE%\.devspace\auth.json
```

自己从这个文件读出来，手动填进浏览器表单。

- 授权**之前**先确认暴露的项目目录正确且足够窄。
- 不要把 Owner password、`ownerToken`、OAuth secret、浏览器 cookie、API key 贴进聊天、issue 或截图。
- `/authorize` 表单没有限流也没有锁定机制，它之所以安全，全靠这个 token 熵足够高——所以永远不要把它
  换成好记的字符串。

跑过 `Rotate`？此前所有授权都已吊销，新的 Owner password 会写进同一个文件，用新值重新授权即可。

### 4. 做只读 smoke test

在交给 ChatGPT 任何正式任务之前，先确认它看到的是你预期的 workspace：

```text
请通过 Codex ChatGPT Bridge 打开当前 workspace，只列出顶层文件，不要写文件，不要运行修改性命令。
```

核对列出的文件是否与你配置的项目目录一致。不一致就先停下，执行 controller `Off`，改好 profile 再继续。

### 常见问题排查

| 现象 | 原因与处理 |
|---|---|
| ChatGPT 报连不上 app | 桥没开，或 tunnel 变了。先跑 controller `Status`，确认是停止状态就执行 `On`。 |
| 之前能用，现在 404 或超时 | Quick Tunnel URL 轮换了。在前面加稳定 Worker / 代理，或者去改 app URL。 |
| 授权表单说密码不对 | 你读的是旧的 `auth.json`。`Rotate` 会替换该值，重新读一遍文件。 |
| 授权成功，但 ChatGPT 看到的文件不对 | `ProjectRoot` / `AllowedRoots` 指向了别处。跑 controller `Doctor`，检查它报告的 roots 和 `securityWarnings`。 |
| 执行 `Off` 之后 ChatGPT 里还留着这个 app | 正常。`Off` 只切断可达性，保留 app 记录，这样下次 `On` 不用重新配置。真要吊销 token 请用 `Rotate`。 |

### 安全提醒

一旦授权，桥就以你的 Windows 用户身份授予文件读写和 shell 执行权限，而且 `run_shell` 不受 root 约束。
root 要窄，不用时执行 controller `Off`，暴露任何你在意的东西之前，先读一遍
[README_zh.md 的安全模型](README_zh.md#安全模型)。
